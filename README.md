# Ebook Template

> A basic template for writing an Ebook with [Quarto](https://quarto.org/)

## 🚀 Getting Started

## Pre-requisites

This project uses [Nix](https://nixos.org/) and [Devenv](https://devenv.sh/) to provide a consistent and isolated dev envrionment with all the required tools.

Check [Devenv | Getting started](https://devenv.sh/getting-started/) for installation instructions.

It´s also recommended to install [direnv](https://direnv.net/).


## Build your book

```sh
task build
```
